ОБЕЗЛИЧИВАНИЕ МТР — v15 FINAL
================================

Статус: FINAL / готово к опытной и рабочей эксплуатации с обязательной проверкой жёлтых REVIEW-позиций.

ЧТО ИЗМЕНЕНО В v15
-------------------
- Excel / XLSM / CSV / PDF с текстовым слоем.
- Сканированные и image-only PDF: автоматический OCR rus+eng.
- OCR-языковые модели rus/eng/osd включены в папку tessdata релиза.
- Для сканов удаляются видимые пиксели совпавших идентификаторов.
- Пакетный выбор нескольких файлов и целой папки.
- Ошибка одного файла не останавливает оставшуюся очередь.
- OCR-устойчивость к перемешиванию колонок: известный ИНН удаляется даже если OCR разорвал или переставил его относительно метки «ИНН».
- Для PDF фирменные правила могут безопасно наследовать подтверждённого производителя из соседнего блока той же визуальной строки.
- Абсолютный KEEP: ОЛ/ОЛК, полный шифр/номер опросного листа, фраза «Комплектация по обосновывающему документу», инвентарные номера.
- Если шифр ОЛ попал внутрь строки, начинающейся с «ТУ», удаляется ТУ-маркер, но полный шифр ОЛ сохраняется.
- KEEP: ГОСТ, DN, PN, SDR, IP, Ex, УХЛ/ХЛ, RAL, марки стали/материала, размеры, давления, температуры и прочие технические параметры.
- Удаляются ИНН/КПП, контакты, поставщики/производители, ТУ, артикулы, подтверждённые бренды/серии/модели, реквизиты писем/ТКП и «Заявка № ...».
- Неоднозначный неизвестный признак не удаляется наугад: строка остаётся REVIEW / жёлтой.

ЗАПУСК В WINDOWS
-----------------
1. Установить Python 3.10+ с python.org, если Python отсутствует.
2. Запустить install_and_run.bat. Он создаст локальное окружение и установит openpyxl + PyMuPDF.
3. Выбрать файлы или папку.
4. Нажать «Обезличить».
5. Проверить жёлтые REVIEW-позиции.

СБОРКА EXE
-----------
Запустить build_exe.bat на Windows. PyInstaller соберёт dist\MTR_Obezlichivatel.exe и включит runtime-базу и tessdata.
Кросс-сборка нативного Windows EXE из текущей Linux-среды не выполняется.
