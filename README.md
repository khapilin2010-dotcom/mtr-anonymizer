Windows-приложение для консервативного обезличивания Excel (`.xlsx`, `.xls`,
`.xlsm`) и PDF. Готовый ZIP собирается workflow **Windows release v16** и
публикуется как artifact `MTR_Obezlichivatel_v16_Windows`.

См. пользовательскую инструкцию: [`ИНСТРУКЦИЯ_v16.md`](ИНСТРУКЦИЯ_v16.md).
