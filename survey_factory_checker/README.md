# SurveyFactoryChecker 0.1 RC1

Отдельная программа для проверки PDF-сборников опросных листов на наличие заводов и организаций. Исходный PDF не изменяется.

## Логика

- **Красный** — найдено название/вариант названия из существующей Excel-базы заводов.
- **Жёлтый** — совпадения по базе нет, но найден признак организации: ООО/АО/ПАО/ОАО/ЗАО/НПО/НПП/ФГУП/ГУП/ИП, ИНН, КПП или подпись «производитель/изготовитель/поставщик».
- Инженер нажимает **Удалить** или **Оставить**. Это фиксирует решение в проверке, но не меняет PDF.
- Для каждой находки показываются файл, страница, найденный фрагмент, основание, завод из базы и контекст.
- Можно загрузить один PDF, несколько PDF или целую папку.
- Отчёт можно выгрузить в XLSX/CSV.

## База заводов

Программа автоматически ищет рядом `MTR_База_обезличивания_v14_BASELINE.xlsx`. При необходимости базу можно выбрать вручную. Поддерживаются столбцы `Завод`, `Изготовитель`, `Производитель`, `Поставщик` и близкие варианты заголовков.

## Ограничение RC1

RC1 читает текстовый слой PDF. Страницы-сканы без текстового слоя учитываются отдельно и не распознаются OCR. Это сознательное ограничение первой версии: сначала проверяем реальные опросные листы и только потом добавляем OCR, если он действительно нужен.

## Windows

`build_windows.bat` собирает `SurveyFactoryChecker.exe` и архив `SurveyFactoryChecker_Windows.zip` вместе с базой заводов.
