# Краткая инструкция — Обезличивание МТР v16

1. Распакуйте ZIP полностью и дважды щёлкните `MTR_Obezlichivatel.exe`. Python устанавливать не нужно.
2. Нажмите **«Выбрать файл»**, **«Выбрать несколько файлов»** или **«Выбрать папку»**, затем **«Начать обработку»**.
3. Результаты с суффиксом `_обезличено` создаются рядом с исходными файлами. Их можно открыть кнопками внизу окна.
4. Зелёный статус означает уверенное применение подтверждённого правила. Жёлтый означает, что исходную позицию нужно проверить вручную; сомнительные данные программа сохраняет.
5. Для сканов требуется установленный Tesseract с языками `rus` и `eng`. Программа проверяет стандартные папки. Если OCR не найден, нажмите **«Выбрать путь к Tesseract»** и укажите `C:\Program Files\Tesseract-OCR` либо его папку `tessdata`.
6. Журнал доступен по кнопке **«Посмотреть журнал»** и хранится в `%LOCALAPPDATA%\MTR_Obezlichivatel\mtr_v16.log`.

База содержит подтверждённые существующие правила проекта, но не заявляется как полная. Всегда просматривайте жёлтые позиции и визуально контролируйте PDF.
