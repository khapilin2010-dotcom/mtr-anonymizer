# MTR Excel 1.5 RC1

Цель версии — перенести в Excel-модуль удачную модель ответственности из PDF-модуля: автоматика помогает, последнее решение остаётся за инженером.

Изменения:

- база `MTR_Knowledge` по умолчанию создаётся рядом с программой;
- отдельный сервер не требуется;
- ранее подтверждённые решения по умолчанию не применяются автоматически;
- стартовая галочка позволяет инженеру сознательно включить автоматическое применение накопленных решений;
- подтверждённые KEEP продолжают защищать текст от лишнего удаления;
- добавлен импорт старых проверенных/обезличенных Excel-выборок с предварительным просмотром конфликтов;
- добавлена выгрузка базы знаний в специальный редактируемый Excel и безопасная обратная загрузка;
- изменение базы не переписывает историю, а создаёт новое аудируемое событие;
- управление знаниями доступно пользователям с правом записи в папку базы;
- существующий зрелый workflow обработки, возврата проверенного Excel, строковой проверки и форматов XLSX/XLSM/XLS/CSV сохранён.
