# MTR Excel 1.2 RC3 — кандидат для приёмки

Разработал Хапилин Виктор.

Распакуйте MTR_Excel_Windows.zip в любую папку и запустите MTR_Excel.exe.
Установка Python и Excel для обработки XLSX/CSV не требуется. База встроена в EXE.

1. Добавьте файлы или папку (включая вложенные папки).
2. Выберите папку результата.
3. Нажмите «Обезличить Excel».
4. Откройте результаты и проверьте четыре добавленных столбца.

Исходный файл остаётся без изменений. Новые файлы имеют суффикс
«_обезличено»; повторный запуск создаёт новый файл с порядковым номером.
Исходные столбцы производителя, кода и наименования не перезаписываются.
Результат содержит: выявленного производителя, обезличенное наименование,
статус с причиной проверки, точные удалённые фрагменты.

Зелёный статус означает прохождение встроенных проверок известных признаков.
Он не доказывает отсутствие неизвестного производителя. Жёлтый статус
требует просмотра; причина указана в ячейке. KEEP имеет приоритет над DELETE:
при конфликте технический фрагмент сохраняется и строка становится жёлтой.

В этой версии исправлена привязка правил к заводам без ИНН, включая названия
с адресом и производителем, найденным по коду Автодокс. Пустые ИНН не объединяют
разные заводы. У подтверждённых названий удаляется и присоединённый через дефис
индекс модели. Добавлены 127 правил по открытым каталогам производителей;
источники каждого дополнения находятся в excel/supplemental_rules.py.

Непроверенные буквенно-цифровые обозначения, аббревиатуры и названия моделей
в остатке дают жёлтый статус с перечнем для проверки. Эта проверка намеренно
строгая: среди жёлтых строк могут быть обычные технические обозначения.
Само наличие производителя в справочнике не подтверждает полноту обезличивания.

Поддерживаются XLSX, XLSM, XLS и CSV (UTF-8/Windows-1251, точка с запятой,
запятая или табуляция, переносы внутри ячеек). Обрабатываются все листы с заголовками МТР, включая
«Готово», «Выборка оборудования» и «выборка_оборудования_все».

Исправления приёмочного прогона:
- Обычные слова «агрегат», «элемент», «блок-бокс», «звезда», «счётчик»,
  «контактор», «полюс» и сокращения не считаются брендом без явной атрибуции.
- Единицы перед значением (например, «Мощность, кВт — 5,50») сохраняются.
- Удаляются реквизиты писем, присоединённые без пробела к ТУ, инвентарному
  номеру или ОЛ. Само обозначение ОЛ сохраняется.
- Дополнено удаление IEK/ИЭК, Schneider Electric, OptiDin, PRIZMA/R,
  PRIZMA/S и Astra Linux в составе комплектного оборудования.
- Убираются названия разработчиков с филиалом и остаточные кавычки.
- Обычные слова через дефис и распознанная масса больше не дают
  самостоятельное предупреждение о модели. Неизвестные индексы проверяются.

Ограничения:
- Формулы в исходных колонках наименования, кода или производителя XLSX/XLSM
  сохраняются и получают отметку о необходимости проверки; формулы не вычисляются.
- XLS с формулами отклоняется: перед обработкой сохраните его в Excel как XLSX.
  Это предотвращает потерю формул старым форматом обработки.
- VBA-архив XLSM сохраняется, макросы не запускаются. Сложные расширения Excel,
  цифровые подписи и нестандартные встроенные объекты требуют отдельной проверки.
- Сборка — кандидат для проверки четырёх реальных файлов, не FINAL.

Ошибочный файл не останавливает очередь. Журнал находится в
%LOCALAPPDATA%\MTR_Excel\mtr_excel.log.

Для сборки разработчиком: Python 3.12, установка excel/requirements.txt и
PyInstaller, затем excel/build_exe.bat. Изолированные тесты:
`python -m pytest tests/excel -q`.
