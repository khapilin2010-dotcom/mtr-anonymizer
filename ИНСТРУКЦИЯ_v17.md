# Краткая инструкция — MTR Anonymizer v17 RC1

1. Полностью распакуйте ZIP и запустите `MTR_Obezlichivatel.exe`. Python устанавливать не требуется.
2. Выберите один файл, несколько файлов или папку и нажмите **«Начать обработку»**.
3. Результаты с суффиксом `_обезличено` создаются рядом с исходными файлами.
4. Зелёный статус означает, что подтверждённых остатков не найдено и KEEP-проверки пройдены. Жёлтый требует ручной инженерной проверки.
5. Для сканированных PDF необходим Tesseract с языками `rus` и `eng`. Если он не найден, укажите папку `Tesseract-OCR` кнопкой в интерфейсе.
6. В табличных PDF колонка **«Код продукции»** сохраняется без изменений, а запись поставщика удаляется целиком внутри своей ячейки.
7. Журнал ошибок открывается кнопкой **«Посмотреть журнал»** и хранится в `%LOCALAPPDATA%\MTR_Obezlichivatel\mtr_v17.log`.

RC1 предназначен для приёмочного тестирования. Реальные производственные PDF в публичный репозиторий не включены.
